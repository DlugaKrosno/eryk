FLOWS
=====

1. User zgłasza incident:
   User → Form → createIncident() → Jira API → Issue created
   → Trigger fires → processIncident() → Rule Engine → Escalation
   → Update issue → Teams notification → Audit log

2. Admin konfiguruje reguły:
   Admin → Admin Panel → Priority Rules tab → Add/Edit Rule
   → saveConfig() → Storage → Audit log

3. Rule evaluation (First Match Wins):
   Trigger → Get rules → Sort by order → For each rule:
   Evaluate conditions → If match: apply priority → STOP
